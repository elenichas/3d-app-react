# 3D Object Editor

A React-based Three.js experiment for selecting and manipulating objects in an interactive 3D scene.

## Features

- Select individual objects in the scene
- Translate, rotate, and scale the active object
- Orbit, pan, and zoom the camera
- Switch transformation mode from an on-canvas control panel
- Dashboard and viewer routes

## Technology

React, TypeScript, Vite, React Three Fiber, Drei, Three.js, Tailwind CSS, and Radix UI.

## Run locally

```bash
git clone https://github.com/elenichas/3d-app-react.git
cd 3d-app-react
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Scope

This is an interaction prototype focused on direct manipulation in a browser-based 3D scene. Scene data is currently defined locally in the application.
